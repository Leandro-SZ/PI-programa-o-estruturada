# PI-programação-estruturada

Sistema HJK — Plataforma Integrada de Gestão Hospitalar

Projeto Integrador de Programação Estruturada desenvolvido para o Hospital JK, uma instituição de saúde particular de grande porte. O sistema tem como objetivo centralizar os processos hospitalares — do primeiro contato do paciente até a emissão de documentos médicos — reduzindo o uso de papel, os erros humanos e o retrabalho entre os setores.

🚧 Status atual: Versão Alfa em desenvolvimento — protótipo em linha de comando (C), com foco em fluxos de navegação, modularização em funções e manipulação de dados em memória (vetores/estruturas de repetição).

🎯 Objetivo Geral

Desenvolver a versão preliminar (versão alfa) de um sistema estruturado em linha de comando para a gestão de atendimentos, triagem e prontuários do Hospital JK, garantindo a consistência das rotinas operacionais identificadas na fase de levantamento de requisitos.

🛠️ Tecnologias
Linguagem: C
Paradigma: Programação Estruturada
Interface: Console (linha de comando)
Armazenamento: Vetores em memória + arquivo texto (.txt)

Curso: Sistemas de Informação / Análise e Desenvolvimento de Sistemas Instituição: UNIEURO — Centro Universitário

📌 Escopo e limitações desta etapa

Funcionalidades descritas no levantamento de requisitos completo — como assinatura digital, integração HL7/API com laboratórios e criptografia avançada — fazem parte da visão de produto final, mas não fazem parte do escopo desta entrega, cujo foco é validar a lógica estruturada e os fluxos essenciais do sistema.
